TRANSPARENCY MATTERS

Privacy policy.

A clear explanation of what this project does today and how privacy is intended to work if the desktop application and Pinterest integration are released.

Last updated: October 19, 2026

Development notice: Crystal Wallpaper Studio is a personal Windows 11 application concept in development. This website is informational only: it does not currently offer Pinterest login, search, or wallpaper downloads. Any description of the future app below is a plan, not a claim that these features are live.

1. Who operates this project

Crystal Wallpaper Studio is an independent, personal software project maintained by the owner of the Crystal-Wallpaper-Studio GitHub repository. It is not affiliated with Pinterest or Microsoft.

2. This website

The current site is a static informational website. It has no account registration, analytics tracker, comment form, or advertising pixels. We do not directly ask you to submit personal information here.

The site is intended to be hosted on GitHub Pages, which may process standard technical information such as IP address, browser details, and access logs when delivering pages. The site also loads fonts from Google Fonts, which may receive connection data such as your IP address. Those services have their own privacy practices. External GitHub and Pinterest links are governed by their respective policies.

3. Planned Pinterest integration

If a Pinterest connection is added to the Windows app, it will be optional and will use Pinterest's approved authorization process. We intend to request only the permissions needed to access the account's authorized boards and Pins, where approved. The purpose would be to help the signed-in user browse their own approved content for wallpaper inspiration.

The application is not intended to collect Pinterest passwords, sell Pinterest data, or publish Pins on a user's behalf. It will not claim access to other people's private boards or unrestricted Pinterest searches. Pinterest content access and permitted uses will be subject to Pinterest's developer terms and any API approval.

Before any Pinterest account connection is released, this policy will be updated to describe the permissions actually requested, how access tokens and any cached data are stored, how long they are kept, and how users can request deletion.

4. Planned desktop application

Proposed features include manual wallpaper selection or randomization and color matching for Windows. We intend to keep user preferences on the user's device wherever practical. No working desktop app or data synchronization service is being offered from this website today.

5. Sharing and retention

We do not currently operate a backend that collects profile data through this website. We do not sell personal information. Hosting and font providers may independently process technical request data as explained above. No Pinterest access tokens are collected through this site. Data retention and any third-party sharing for a future desktop release will be disclosed before those features become available.

6. Your choices

You do not need a Pinterest account to view this site. A future Pinterest connection, if available, will be optional and subject to Pinterest's authorization controls; Pinterest account permissions can also be reviewed in Pinterest account settings. You can stop visiting this website at any time.

7. Security

This site does not ask you to submit passwords, API secrets, or tokens. Please never post private credentials in a public GitHub issue. Any future login feature will require a security review and a policy update before release.

8. Policy changes

We may update this policy as the application is developed or third-party integrations change. A revised date will appear at the top of this page. Material changes affecting a released app will be disclosed before implementation as appropriate.

9. Questions or requests

For project or privacy questions, please use the GitHub repository's issue tracker. GitHub issues are public; do not include passwords, tokens, or other sensitive personal information.
